📦 Extension Distribution & Installation Guide

How to give the authorized extension to your students or users:

  1. Open Google Chrome and navigate to chrome://extensions/.
  2. Toggle "Developer mode" ON in the top-right corner.
  3. Click "Load unpacked" and select the java_coding folder from this workspace.
  4. Pin "LMS Java Coding Helper" to the toolbar.
  5. When opening the extension popup, students enter their User ID and Password created in this Admin Portal.
  6. The extension binds automatically to their machine on first login and runs until the expiration date!

1. Cloud Firestore Rules (Recommended)

Go to Firebase Console > Firestore Database > Rules and paste: 

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // Admin accounts and credentials
    match /admins/{adminId} {
      allow read, write: if true;
    }
    // Student users, passwords, and device locks
    match /users/{userId} {
      allow read, write: if true;
    }
    // Global & system settings
    match /system_settings/{settingId} {
      allow read, write: if true;
    }
    // Live extension activity & audit logs
    match /activity_logs/{logId} {
      allow read, write: if true;
    }
  }
}

2. Realtime Database Rules (Optional Fallback)

Go to Firebase Console > Realtime Database > Rules and paste: 

{
  "rules": {
    "admins": {
      ".read": true,
      ".write": true
    },
    "users": {
      ".read": true,
      ".write": true
    },
    "system_settings": {
      ".read": true,
      ".write": true
    },
    "activity_logs": {
      ".read": true,
      ".write": true
    }
  }
}
